# Weather App

Простое веб-приложение для просмотра текущей погоды в любом городе.

## Функциональность

- Поиск погоды по названию города
- Отображение текущей температуры
- Отображение описания погоды
- Отображение влажности
- Отображение скорости ветра
- Кнопка очистки поля ввода
- Адаптивный дизайн

## Технологии

- Node.js
- Express.js
- OpenWeatherMap API
- HTML5
- CSS3
- JavaScript (ES6+)

## Установка

1. Клонируйте репозиторий:
```bash
git clone [url-репозитория]
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл .env в корневой директории и добавьте ваш API ключ:
```
API_KEY=ваш_ключ_openweathermap
PORT=5500
```

4. Запустите сервер:
```bash
node src/server.js
```

5. Откройте приложение в браузере:
```
http://localhost:5500
```

## Использование

1. Введите название города в поле ввода
2. Нажмите кнопку "Узнать погоду"
3. Получите информацию о текущей погоде в выбранном городе
